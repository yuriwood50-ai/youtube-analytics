# YouTube 분석 대시보드

YouTube Data API v3로 채널·키워드 데이터를 모아 분석하기 쉽게 보여 주는 로컬 웹 페이지입니다.

## 실행

1. `.env` 에 `YOUTUBE_API_KEY=` 값이 있는지 확인 (없으면 `copy .env.sample .env` 후 입력)
2. `run_dashboard.bat` 더블클릭 — 또는 터미널에서

   ```
   python main.py
   ```

3. 브라우저에서 `http://127.0.0.1:8000/` 이 열립니다. 끝낼 때는 서버 창에서 `Ctrl+C`.

## 볼 수 있는 것

| 화면 | 내용 |
|---|---|
| 채널 분석 | @핸들·채널 URL·채널 ID·영상 URL 로 채널을 찾아 최근 영상 최대 200개 분석 |
| 키워드 검색 | 검색어·정렬·기간·지역으로 영상 최대 100개 모아 비교 |
| 필터 | 기간 / 길이(3분 이하·초과) / 제목·태그 검색 — 아래 모든 지표·차트·표에 한 번에 적용 |
| 핵심 지표 | 중앙값 조회수, 조회수 합계, 참여율, 좋아요율, 구독자 대비 조회수, 업로드 간격 |
| 차트 | 영상별 추이(지표 선택·로그 축), 조회수×참여율, 요일별, 업로드 시간표, 길이별, 태그별, 채널별(검색) |
| 영상 목록 | 모든 열 정렬, 중앙값 대비 2배 이상 ▲ 표시, CSV 내보내기(엑셀 한글 호환) |

## 할당량 (하루 기본 10,000)

- 채널 분석: 1회 약 3~10 (영상 50개당 약 2)
- 키워드 검색: 50개당 100
- 같은 요청은 10분 동안 서버 메모리에 캐시되어 다시 쓰지 않습니다.

## API 키 보안

- 키는 `.env` 에만 있고 `.gitignore` 로 커밋에서 제외됩니다. 코드·HTML·JS 어디에도 키를 적지 않습니다.
- 브라우저는 키를 모릅니다. 페이지는 로컬 서버(`/api/...`)만 부르고, 서버가 키를 붙여 Google에 요청합니다.
- 키는 URL 대신 `X-Goog-Api-Key` 헤더로 보내서 주소·로그·오류 메시지에 남지 않습니다.
- 서버는 `127.0.0.1` 에만 열려서 같은 와이파이의 다른 기기도 접속할 수 없고, 다른 웹사이트가 몰래 호출하는 요청(DNS 리바인딩, 교차 출처)도 거부합니다.
- 정해진 파일(`index.html`, `app.js`, `style.css`)만 내보내므로 `.env` 는 주소를 알아도 받을 수 없습니다.

권장 설정 ([Google Cloud 콘솔 → 사용자 인증 정보](https://console.cloud.google.com/apis/credentials)):

- **API 제한사항 → 키 제한 → YouTube Data API v3** 만 허용
- 애플리케이션 제한은 “없음” 또는 “IP 주소”로 두세요. “웹사이트(HTTP 리퍼러)” 제한은 서버 호출과 맞지 않아 요청이 거부됩니다.
- 키가 노출됐다고 의심되면 콘솔에서 **키 다시 생성** 후 `.env` 만 바꾸면 됩니다.
- 이 폴더는 OneDrive 로 동기화됩니다. `.env` 도 OneDrive 클라우드에 올라가니, 폴더를 다른 사람과 공유할 때는 `.env` 를 빼고 공유하세요.

## Vercel 배포

- GitHub 저장소(비공개)와 연결되어 있어 `main` 브랜치에 push 하면 자동으로 다시 배포됩니다.
- 배포본에서는 `api/*.py` 함수가 로컬 서버 대신 `/api` 를 처리합니다. (공통 로직 `dashboard_api.py`)
- **API 키는 Vercel 프로젝트 → Settings → Environment Variables 에 `YOUTUBE_API_KEY` 로 직접 넣으세요.**
  저장소와 Vercel 업로드(`.vercelignore` 허용 목록)에는 `.env` 가 절대 포함되지 않습니다. 키를 넣거나 바꾼 뒤에는 재배포해야 적용됩니다.
- 배포 주소는 누구나 열 수 있습니다. 할당량이 빨리 줄면 Vercel 방화벽(Firewall) 규칙이나 접속 코드 추가를 고려하세요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 로컬 실행 진입점 (`--port`, `--no-browser`) |
| `server.py` | 로컬 전용 HTTP 서버 (127.0.0.1) |
| `dashboard_api.py` | `/api` 처리 공통 로직 (로컬·Vercel 공용) |
| `api/*.py` | Vercel 함수 (`/api/status`, `/api/channel`, `/api/search`) |
| `youtube_api.py` | YouTube API 호출·캐시·오류 안내 |
| `config.py` | 로컬에서 `.env` 의 키 읽기 |
| `public/` | 대시보드 화면 (HTML·CSS·JS, 외부 라이브러리 없음) |
| `vercel.json`, `.vercelignore` | Vercel 설정·업로드 허용 목록 |
